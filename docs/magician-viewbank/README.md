# MAGICIAN 离线视点库设计

本目录定义 CARLA 与 MAGICIAN 的第一阶段集成边界。它只描述计划中的功能，不能当成已实现说明。

- [需求分析](requirements.md)：说明要解决的问题、范围、约束、验收条件和实验公平性要求。
- [概要设计](high-level-design.md)：说明模块边界、数据格式、坐标转换、闭环流程和分阶段实现顺序。

第一阶段采用离线视点库：CARLA 负责在一个固定小区域采集同步 RGB-D、位姿和诊断标签；MAGICIAN
把视点库当作可查询环境，执行“真实观察—更新场景表示—想象候选视点—束搜索—执行一步—重新规划”的闭环。
所有候选视点的真实图像可以预先存盘，但规划器只能读取已经执行到的节点，避免提前看到答案。
