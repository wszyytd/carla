# 研究路线

## 阶段一：平台连接

确认 CARLA 0.10.0 Python API 能连接服务器、读取 `Town10HD_Opt`，并可靠报告超时和
版本信息。

## 阶段二：城市交通

使用 Traffic Manager 生成目标车辆和背景车辆，验证车辆能够沿道路行驶、处理路口、
交通灯和其他车辆。所有 Actor 必须可追踪并安全清理。

## 阶段三：空中观测

把可移动空中传感器作为第一阶段的无人机抽象，同帧采集 RGB、深度和实例分割。相机
创建或换位后先预热，稳定帧才计入正式样本。

## 阶段四：平台 A/B 对照

在相同车辆、距离、FOV 和分辨率条件下比较 CARLA 与 CarlaAir 的目标像素、检测效果、
标签稳定性、同步性、FPS 和交通可控性。重点条件包括 1080p、90°/30°、100/150 米。

## 阶段五：固定路径实验

构造单车经过建筑并发生遮挡的最小场景，比较尾随绕行、另一侧抄近路、前方等待、
原地等待和上升越障。指标包括重观测时间、丢失时长、路径长度、目标像素和检测置信度。

## 阶段六：世界模型

只有当不同固定路径各有优劣，且最优路径确实依赖车辆未来转向、遮挡结构或观测约束时，
才定义世界模型的输入、输出和训练数据。如果一条固定策略在所有场景中稳定最优，就不应
为了使用世界模型而增加模型复杂度。

## 当前边界

现阶段不做目标检测器训练、世界模型训练、AirSim 飞行动力学、大规模数据采集、CARLA
源码编译或自动部署。
